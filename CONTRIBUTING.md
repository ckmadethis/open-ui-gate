# Contributing

OpenUI Gate is intentionally small. Good contributions make the gate more
useful without turning it into a full design system.

## Useful Issues

- False positives from real frontend code.
- Missing rules that catch repeated AI-generated UI patterns.
- Fixture cases that show clear pass/fail behaviour.
- Hook examples for agent workflows.

## Pull Requests

1. Add or update a fixture when changing rule behaviour.
2. Run `npm test`.
3. Keep rule messages specific and short.
4. Avoid unverifiable design claims or fake quality metrics.
